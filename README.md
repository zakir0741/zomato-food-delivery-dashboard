# 🍽️ Zomato Food Delivery Dashboard

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze Zomato
food delivery data and provide insights into orders, revenue,
customers, restaurants and delivery performance.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel
